# Задача 1. K-th minheap

## Контракт

* find_kth_largest(nums, k) -> int — k-й по величине элемент
* find_kth_largest_heapq(nums, k) -> int — то же через heapq.

k = 1 — максимум, k = n — минимум. Массив не сортируем целиком
и не мутируем.

Примеры:

* nums = [3,2,1,5,6,4], k = 2 → 5
* nums = [3,2,3,1,2,4,5,5,6], k = 4 → 4

## Объяснение решения

Идея: держим min-heap размера ровно k, в которой лежат k наибольших
элементов, встреченных на текущий момент. Корень кучи, это наименьший
среди этих k, это кандидат на ответ k-й по величине.

Алгоритм (одинаков для обеих реализаций):

1. Идём по nums слева направо.
2. Пока в куче меньше k элементов — кладём текущий (push / heappush).
3. Если куча полна и x > heap[0] — текущий больше минимума «топ-k»,

   значит минимум вытесняется: заменяем корень на x и восстанавливаем
    кучу (sift_down / heapreplace).
4. Если x ≤ heap[0] — он не входит в топ-k, пропускаем.
5. После прохода heap[0] — ровно k-й по величине.

**Почему корректно.** После обработки префикса куча содержит
min(i, k) наибольших элементов этого префикса, при i ≥ k корень =
k-й среди них. Когда префикс = весь массив, корень = k-й по величине
во всём nums. Дубликаты обрабатываются естественно (сравнение >).

## Оценка сложности

Пусть n = len(nums).

| | Время | Память |
|---|---|---|
| обе реализации | O(n log k) | O(k) на кучу |

* Каждая из ≤ n операций с кучей размера ≤ k стоит O(log k).
* Вход не копируем целиком → доп. память O(k).
* Полная сортировка была бы O(n log n) и O(n) памяти на копию —
при k ≪ n куча выгоднее.

## Визуализация

nums = [3, 2, 1, 5, 6, 4], k = 2. Нужен 2-й по величине = 5.

| шаг | x | действие | min-heap (размер ≤ 2) | корень |
|-----|-----|----------|------------------------|--------|
| 1 | 3 | push (куча неполна) | [3] | 3 |
| 2 | 2 | push | [2, 3] | 2 |
| 3 | 1 | 1 ≤ 2 — пропуск | [2, 3] | 2 |
| 4 | 5 | 5 > 2 — replace root | [3, 5] | 3 |
| 5 | 6 | 6 > 3 — replace root | [5, 6] | 5 |
| 6 | 4 | 4 ≤ 5 — пропуск | [5, 6] | 5 |

Ответ: **5**. Проверка: по убыванию [6, 5, 4, 3, 2, 1], 2-й = 5.
