# Задача 1. Палиндром

## Объяснение решения

Идея: построить число, записанное цифрами в обратном порядке, и сравнить его с исходным.

Реализация:
- отрицательные числа сразу отклоняем;
- числа от `0` до `9` — всегда палиндромы;
- если число заканчивается на `0` (и это не ноль), не палиндром;
- иначе сохраняем `original`, в цикле берем младшую цифру и дописываем её в `reversed_num`, пока `num` не станет `0`;
- в конце делаем прооверку `reversed_num == original`.

## Оценка сложности

Пусть `d` — число цифр во входе (`d = ⌊log₁₀ n⌋ + 1`).

| | Сложность | Почему |
|---|---|---|
| **Время** | `O(d)` = `O(log n)` | один проход по цифрам |
| **Память** | `O(1)` | целые переменные |

## Визуализация работы алгоритма

Пример: `n = 1000001` — семь цифр, нули в середине, единицы по краям.
Нельзя пропускать нули (не знаю какой еще коварный пример сделать).

| Шаг | `num` | `num % 10` | `reversed_num` после шага |
|-----|-------|------------|---------------------------|
| старт | 1000001 | — | 0 |
| 1 | 100000 | 1 | 1 |
| 2 | 10000 | 0 | 10 |
| 3 | 1000 | 0 | 100 |
| 4 | 100 | 0 | 1000 |
| 5 | 10 | 0 | 10000 |
| 6 | 1 | 0 | 100000 |
| 7 | 0 | 1 | 1000001 |

`reversed_num == original` → `1000001 == 1000001` → **True**.
