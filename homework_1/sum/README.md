# Задача 2. Сумма

## Объяснение решения

Берём все элементы: это заведомо максимальная возможная сумма. Дальше смотрим на чётность.

- Если сумма уже чётная — она и есть ответ.
- Если нечётная — среди элементов есть нечётное число нечётных. Чтобы сумма осталась максимальной, убираем наименьшее нечётное.

## Оценка сложности

Пусть `n` — длина массива.

| | Сложность | Почему |
|---|---|---|
| **Время** | `O(n)` | один проход для суммы + один для поиска минимума среди нечётных (константу отбрасываем) |
| **Память** | `O(1)` | ничего не делали с масивом |

## Визуализация работы алгоритма

### Пример с дубликатами: `nums = [3, 3, 5, 5]`

1. `total = 3 + 3 + 5 + 5 = 16` — **чётно**.
2. Ранний `return 16` — убирать ничего не нужно.

Ответ: **16**.

### Пример, когда сумма нечётная: `nums = [3, 3, 5]`

1. `total = 3 + 3 + 5 = 11` — **нечётно**.
2. Нечётные: `3, 3, 5` → наименьшее = `3` (любой из двух одинаковых).
3. `11 - 3 = 8`

Ответ: **8**.
