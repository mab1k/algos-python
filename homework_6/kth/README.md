# Задача 3. K-th

## Контракт

`find_kth_largest(nums, k) -> int` — **k-й по величине** элемент: `k = 1` — максимум, `k = n` — минимум.

Ограничения из условия: **нельзя** полностью сортировать массив и
**нельзя** использовать кучу. Используем **quickselect**.

Примеры:

* `nums = [3,2,1,5,6,4], k = 2` → `5`
* `nums = [3,2,3,1,2,4,5,5,6], k = 4` → `4`

## Объяснение решения

В отсортированном по неубыванию массиве k-й по величине стоит на индексе
`n - k`. Quickselect находит элемент, который оказался бы на этом месте
после сортировки, не сортируя всё:

1. делаем partition (Lomuto) на текущем отрезке `[lo, hi]`;
2. pivot встаёт на индекс `p`;
3. если `p == target` — это ответ;
4. если `p < target` — ответ справа, иначе слева.

Чтобы реже ловить `O(n²)` на почти-сортированных входах, pivot, это
медиана из трёх (`lo`, `mid`, `hi`).

**Корректность.** После partition все слева `≤ a[p]`, все справа `≥ a[p]`,
значит `a[p]` элемент ранга `p` в текущем массиве-копии. Сужая поиск
к стороне, где лежит `target`, сохраняем инвариант нужный ранг внутри
`[lo, hi]`. Когда `p = target`, найден нужный ранг.

## Оценка сложности

Пусть `n = len(nums)`.

| | Сложность | Почему |
|---|---|---|
| **Время (средн.)** | `Θ(n)` | `T(n) ≈ T(n/2) + Θ(n)` → геометрическая сумма |
| **Время (худш.)** | `Θ(n²)` | каждый раз отрезаем по 1 элементу |
| **Память** | `O(n)` на копию + `O(1)` доп. (цикл вместо рекурсии) | вход не мутируем |

Полная сортировка была бы `Θ(n log n)`, quickselect выкидывает половину
на каждом шаге в среднем.

## Визуализация работы алгоритма

`nums = [3, 2, 1, 5, 6, 4]`, `k = 2` → ищем индекс `target = 6 - 2 = 4`
(5-й в 0-based при сортировке по возрастанию = 2-й с конца).

Копия: `[3, 2, 1, 5, 6, 4]`, отрезок `[0, 5]`.

| Шаг | отрезок | pivot (после median-of-3) | после partition | `p` vs `4` |
|-----|---------|---------------------------|-----------------|------------|
| 1 | `[0..5]` `[3,2,1,5,6,4]` | `4` | `[3,2,1,4,6,5]` | `p=3 < 4` → идём вправо |
| 2 | `[4..5]` `[6,5]` | `5` | `[5,6]` | `p=4 == 4` → ответ `5` |

Проверка: по убыванию `[6,5,4,3,2,1]`, 2-й = `5`.

Второй пример: `k=4` в `[3,2,3,1,2,4,5,5,6]` → по убыванию
`[6,5,5,4,…]`, 4-й = `4`.
