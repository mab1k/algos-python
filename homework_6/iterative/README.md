# Задача 2. Iterative

## Контракт

Модуль: `iterative_sorts.py`.

* `mergesort_iterative(arr) -> list[int]` — mergesort без рекурсии.
* `quicksort_iterative(arr) -> list[int]` — quicksort на явном стеке `(lo, hi)`.
* Входной список не мутируется.

## Объяснение решения

**mergesort.** Начинаем с «отсортированных» кусков длины 1.
На шаге `width` сливаем соседние пары сегментов длины `width` в сегменты
`2·width`. `width` удваивается, пока не покроет весь массив. Та же логика,
что у рекурсивного mergesort, только уровни дерева идут снизу вверх.

**Итеративный quicksort.** Рекурсивные вызовы `_quicksort(lo, hi)` заменяем
стеком границ. Пока стек не пуст: достаём интервал, делаем partition,
кладём обратно ненулевые половины. Порядок «сначала большая сторона»
уменьшает пиковый размер стека (как хвостовая оптимизация).

**Корректность.** Mergesort: после фазы `width` каждый блок длины
`min(2·width, …)` отсортирован (слияние двух отсортированных). Quicksort:
тот же инвариант partition, что в рекурсивной версии; стек хранит ровно
те подинтервалы, которые ещё нужно отсортировать.

## Оценка сложности

Пусть `n = len(arr)`.

| Алгоритм | Время | Доп. память |
|----------|-------|-------------|
| mergesort_iterative | `Θ(n log n)` всегда (`log n` фаз × `Θ(n)` на слияния) | `O(n)` буфер |
| quicksort_iterative | средн. `Θ(n log n)`, худш. `Θ(n²)` | стек средн. `O(log n)`, худш. `O(n)` + копия |

Рекурсивный стек вызовов заменён явным асимптотика та же, нет риска
`RecursionError` на вырожденном quicksort (для очень больших `n` стек
списка всё равно `O(n)` по памяти, но не по лимиту C-стека Python).

## Визуализация работы алгоритма

`arr = [5, 2, 4, 1, 3]`.

### Mergesort bottom-up

| width | сегменты до merge | после фазы |
|-------|-------------------|------------|
| 1 | `[5][2] [4][1] [3]` | `[2,5] [1,4] [3]` |
| 2 | `[2,5]+[1,4]` и хвост `[3]` | `[1,2,4,5] [3]` |
| 4 | `[1,2,4,5]+[3]` | `[1, 2, 3, 4, 5]` |

### Quicksort со стеком (pivot = последний)

Старт: стек `[(0, 4)]`, массив `[5, 2, 4, 1, 3]`.

1. partition по `3` → `[2, 1, 3, 5, 4]`, `p = 2`;
2. стек ← `(0,1)`, `(3,4)`;
3. `(3,4)`: pivot `4` → `[2, 1, 3, 4, 5]`;
4. `(0,1)`: pivot `1` → `[1, 2, 3, 4, 5]`;
5. стек пуст → готово.
