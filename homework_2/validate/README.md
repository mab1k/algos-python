# Задача 2. Validate

## Объяснение решения

Симулируем работу стека:

1. Идём по `pushed` слева направо и кладём каждый элемент в стек.
2. Пока вершина стека совпадает с текущим ожидаемым элементом из `popped`, делаем `pop` и сдвигаем указатель в `popped`.
3. Если после всех `push` указатель дошёл до конца `popped` — последовательность возможна, иначе нет.

## Оценка сложности

Пусть `n = len(pushed)`.

| | Сложность | Почему |
|---|---|---|
| **Время** | `O(n)` | каждый элемент ровно один раз входит в стек и не больше одного раза выходит |
| **Память** | `O(n)` | стек в худшем случае хранит все `n` элементов |

## Визуализация работы алгоритма

Пример: `pushed = [1, 2, 3, 4, 5]`, `popped = [1, 3, 5, 4, 2]` → **True**.

| Шаг | Действие | Стек (дно → верх) | `j` |
|-----|----------|-------------------|----------------|
| 1 | push 1 | `[1]` | 0 → 1 |
| 2 | pop 1 | `[]` | 1 → 3 |
| 3 | push 2 | `[2]` | 1 → 3 |
| 4 | push 3 | `[2, 3]` | 1 → 3 |
| 5 | pop 3 | `[2]` | 2 → 5 |
| 6 | push 4 | `[2, 4]` | 2 → 5 |
| 7 | push 5 | `[2, 4, 5]` | 2 → 5 |
| 8 | pop 5 | `[2, 4]` | 3 → 4 |
| 9 | pop 4 | `[2]` | 4 → 2 |
| 10 | pop 2 | `[]` | 5 (конец) |

`j == n` → **True**.
