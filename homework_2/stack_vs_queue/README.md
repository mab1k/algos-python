# Задача 1. Stack vs Queue

## Объяснение решения

Обе структуры построены на односвязном списке

**Стек (LIFO).** Все операции у головы списка:
- `push` — новый узел становится головой;
- `pop` / `peek` — читаем и при необходимости снимаем голову.

Так последний добавленный элемент всегда наверху.

**Очередь (FIFO).** Держим два указателя — голову и хвост:
- `enqueue` — добавляем узел после хвоста и сдвигаем хвост;
- `dequeue` / `peek` — работаем с головой, если список опустел, обнуляем и хвост.

Так первый добавленный выходит первым.

## Оценка сложности

Все операции стека и очереди — константные по числу шагов (перестановка нескольких ссылок).

| | Сложность | Почему |
|---|---|---|
| **Время** (push/pop/enqueue/dequeue/peek) | `O(1)` | работа только с головой и/или хвостом |
| **Память** | `O(n)` | один узел на каждый из `n` элементов |

## Визуализация работы алгоритма

### Стек: `push(1), push(2), pop()`

| Шаг | Операция | Список (голова слева) | Результат |
|-----|----------|------------------------|-----------|
| старт | — | (пусто) | — |
| 1 | `push(1)` | `1` | — |
| 2 | `push(2)` | `2 → 1` | — |
| 3 | `pop()` | `1` | `2` |

### Очередь: `enqueue(1), enqueue(2), dequeue()`

| Шаг | Операция | Список (голова → хвост) | Результат |
|-----|----------|--------------------------|-----------|
| старт | — | (пусто) | — |
| 1 | `enqueue(1)` | `1` | — |
| 2 | `enqueue(2)` | `1 → 2` | — |
| 3 | `dequeue()` | `2` | `1` |
