# Задача 3. Merge lists

## Объяснение решения

Даны два **уже отсортированных** односвязных списка. Нужно собрать один отсортированный список.

На каждом шаге берём узел с меньшим `val` из двух текущих голов и добавляем его к результату, сдвигая указатель в соответствующем списке. Когда один список закончился добавляем хвост результата.

Реализованы **два варианта**:

1. **С фиктивным элементом (`merge_with_dummy`).** Создаём временный узел `dummy`. Указатель `curr` всегда указывает на последний узел результата, новые узлы цепляем к `curr.next`. В конце возвращаем `dummy.next`.

2. **Без фиктивного элемента (`merge_without_dummy`).** Сначала обрабатываем пустые входы и явно выбираем голову результата (меньший из двух первых узлов). Дальше тот же цикл слияния от уже выбранной головы.

## Оценка сложности

Пусть `n` и `m` — длины списков.

| | Сложность | Почему |
|---|---|---|
| **Время** | `O(n + m)` | каждый узел посещается и присоединяется ровно один раз |
| **Память** | `O(1)` | фиктивный узел это константа |

## Визуализация работы алгоритма

Пример: `list1 = [-5, -1, 0]`, `list2 = [-3, 2]`.

### С фиктивным элементом

| Шаг | Сравниваем | Берём | Результат после шага (`dummy → …`) |
|-----|------------|-------|-------------------------------------|
| старт | — | — | `dummy` |
| 1 | -5 vs -3 | list1: -5 | `dummy → -5` |
| 2 | -1 vs -3 | list2: -3 | `dummy → -5 → -3` |
| 3 | -1 vs 2 | list1: -1 | `dummy → -5 → -3 → -1` |
| 4 | 0 vs 2 | list1: 0 | `dummy → -5 → -3 → -1 → 0` |
| хвост | — | list2: 2 | `dummy → -5 → -3 → -1 → 0 → 2` |

Возвращаем `dummy.next` → `[-5, -3, -1, 0, 2]`.

### Без фиктивного элемента

| Шаг | Действие |
|-----|----------|
| выбор головы | `-5 ≤ -3` → `head = list1` (`-5`), дальше list1 = `[-1, 0]` |
| дальше | тот же цикл: -3 (list2), -1, 0, затем хвост 2 |
| итог | `head` указывает на `[-5, -3, -1, 0, 2]` |
