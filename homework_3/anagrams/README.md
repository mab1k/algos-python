# Задача 2. Anagrams

## Контракт

Решение — функция `group_anagrams(strs) -> list[list[str]]`.
Порядок групп и порядок слов внутри группы условием не зафиксированы;
в тестах сравнение идёт после сортировки. Предполагаются строчные
латинские буквы `a`–`z`. Чтение stdin не требуется — проверяется функция.

## Объяснение решения

Два слова — **анаграммы**, если одно можно получить перестановкой букв другого.

Мультисет кодируем вектором частот длины 26: для символа `c` увеличиваем
ячейку `ord(c) - ord('a')`. Ключ группы — `tuple` этого списка.
Все анаграммы получают один ключ, слова с разным мультисетом — разные.

Алгоритм: один проход по списку, слова с одинаковым ключом складываем
в одну группу (словарь `ключ → список слов`).

Почему не сортировка и не `Counter`: сортировка даёт `O(L log L)` на слово,
`Counter` для хешируемого ключа всё равно нужно привести к фиксированному
порядку (по сути тот же count-вектор). Список частот по ASCII выигрывает:
`O(L + Σ)` на слово при `Σ = 26`.

### Доказательство корректности

**Полнота ключа.** Вектор частот длины 26 однозначно задаёт мультисет
букв `a`–`z` и наоборот. Значит слова попадают в одну группу тогда
и только тогда, когда они анаграммы. Лишних объединений и пропусков нет.

## Оценка сложности

Пусть `n` — число слов, `L` — максимальная длина слова, `Σ = 26`.

| | Сложность | Почему |
|---|---|---|
| **Время** | `O(n · (L + Σ)) = O(n · L)` | один проход по буквам + копирование вектора в `tuple` |
| **Память** | `O(n · (L + Σ))` | слова плюс ключи длины `Σ` |

(Сортировка была бы `O(n · L log L)` — хуже при больших `L`.)

## Визуализация работы алгоритма

Нетривиальный пример: слова с общими буквами, но **разным** числом вхождений.

`strs = ["aab", "aba", "abb", "bab", "bba", "ab"]`

Ниже в ключе показаны только ненулевые счётчики `a`, `b`
(остальные 24 позиции — нули).

| Слово | счётчик → ключ | Группа после шага |
|-------|----------------|-------------------|
| `aab` | `a:2, b:1` | `A: [aab]` |
| `aba` | `a:2, b:1` | `A: [aab, aba]` |
| `abb` | `a:1, b:2` | `A: [aab, aba]`, `B: [abb]` |
| `bab` | `a:1, b:2` | `A: …`, `B: [abb, bab]` |
| `bba` | `a:1, b:2` | `A: …`, `B: [abb, bab, bba]` |
| `ab`  | `a:1, b:1` | `A: …`, `B: …`, `C: [ab]` |

`aab` и `abb` делят алфавит `{a, b}`, но векторы
`(2,1,…)` и `(1,2,…)` различны → **разные ключи**, разные группы.
Короткая `ab` с вектором `(1,1,…)` не попадает ни к одной из них.

Итог: `[["aab", "aba"], ["abb", "bab", "bba"], ["ab"]]`.
